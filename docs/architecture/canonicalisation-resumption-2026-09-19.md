## Review coverage correction

The earlier audit linked every file under a registered asset directory to its
bounded review. Since the 10 September checkpoint, files in those directories
have been added and modified. A directory match cannot extend a past review to
those bytes.

The new review baseline preserves the 120 file receipts in
`LameziaTrasparente_canonicalisation_audit_1214.json`, whose SHA-256 is
`db88ea072fe2f55daa8309463dd058eb5a240660866c8325c463fd78eb4e9450` and whose
source commit is `1bb355a1c4d91d03b04d61bb4d55592fd09f30b8`.

The current audit distinguishes directory ownership from review validity.
Only matching bytes and matching asset ownership retain the original bounded
review link. New files, modified content and changed ownership remain
unreviewed with a null semantic status and an explicit reason. Invalid receipts
fail closed. A missing old file is reported separately; absence does not
establish a justified deprecation. The baseline is not refreshed merely to make
the current counts look better.

Counts are generated by `pnpm run architecture:canonicalisation`. Files, groups,
source rows, observations and production gates remain separate denominators.
